# Changelog

## 1.0.0

- Клиент AmneziaWG на `amneziawg-go` v3.1.20261116 и `amneziawg-tools` v3.1.20260812, без модуля ядра.
- В туннель уходят только домены из списка (вместе с поддоменами) и указанные IPv4 CIDR. Маршрут по умолчанию хоста не меняется.
- Строгий режим по умолчанию: без свежего handshake выбранные назначения отбрасываются.
- DNS-форвардер на шлюзе сети hassio добавляет A-записи в nftables. AAAA этих имён подменяется на discard-адрес.
- Состояние туннеля публикуется в Home Assistant: handshake, rx/tx, up/down и число адресов в наборе.
