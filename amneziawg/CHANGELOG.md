# Changelog

## 1.0.1

- Образы amd64 и aarch64 собираются в GitHub Actions и публикуются в GHCR. Установка на Home Assistant больше не компилирует дополнение на устройстве.

## 1.0.0

- Клиент AmneziaWG на `amneziawg-go` v3.1.20261116 и `amneziawg-tools` v3.1.20260812, без модуля ядра.
- В туннель уходят только адреса, увиденные в DNS-ответах для имён из списка (и их поддоменов), плюс статические IPv4 CIDR. Свой DNS-сервер не запускается, настройки DNS Home Assistant не меняются.
- Выученные адреса пишутся в `/data/learned.json` и после перезапуска сразу возвращаются в набор маршрутизации.
- Строгий режим по умолчанию: без свежего handshake выбранные назначения отбрасываются. Увиденные AAAA в строгом режиме тоже отбрасываются: IPv6 в туннель не заворачивается.
- Состояние туннеля публикуется в Home Assistant: handshake, rx/tx, up/down, число адресов в наборе и счётчик увиденных DNS-ответов.
